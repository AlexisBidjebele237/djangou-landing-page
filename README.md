## 🎯 À propos de DJANGOU

**DJANGOU** est une plateforme EdTech de gestion scolaire conçue spécifiquement pour répondre aux défis des environnements où la connexion internet est instable ou coûteuse. 

Cette Landing Page marketing publique présente la solution DJANGOU. Elle a été développée avec une architecture "Vanilla" (HTML, CSS, JS purs) pour garantir des **performances maximales**, une **accessibilité totale** et une **optimisation SEO/GEO de pointe**.

---

## ✨ Fonctionnalités Clés

- 🌍 **Architecture Offline-First** : Continuez à travailler normalement même lorsque la connexion internet est coupée. Les données sont synchronisées automatiquement au retour du réseau.
- 🎙️ **Dictée Vocale Intelligente** : Énoncez vos notes à voix haute. L'IA les comprend et remplit automatiquement le tableau des élèves.
- 📸 **Scan et OCR par IA** : Photographiez les copies, l'IA extrait les informations pour réduire la saisie manuelle.
- 📊 **Bulletins PDF en masse** : Générez instantanément des bulletins scolaires professionnels au format PDF pour toute une classe.
- 🧮 **Barèmes Automatisés** : Calcul automatique et rapide des moyennes globales sans erreur.

## 🚀 Technologies et Performances

Ce projet a été conçu selon des règles strictes de performance et de SEO technique (Core Web Vitals, Google Lighthouse, Chrome Canary) :

*   **Zéro Dépendance Lourde** : Aucun framework (ni React, ni Vue, ni Tailwind). Tout est codé en HTML sémantique, CSS Vanilla (avec variables) et JavaScript natif.
*   **Animations Optimisées** : Utilisation exclusive de `transform` et `opacity` pour garantir 60 FPS sur mobile. Animations 3D (tilt) et Scroll Reveal gérées via `IntersectionObserver`.
*   **Accessibilité (a11y)** : Support clavier complet, balises `aria`, contraste respecté, support de `prefers-reduced-motion` et `prefers-color-scheme`.
*   **SEO & GEO (Generative Engine Optimization)** :
    *   Balisage Schema.org (`SoftwareApplication`, `FAQPage`) en JSON-LD.
    *   Fichiers `robots.txt` et `sitemap.xml` inclus.
    *   Balises Open Graph et Twitter Cards pour les réseaux sociaux.
*   **Dark Mode Natif** : Système de thème clair/sombre adaptatif avec persistance via `localStorage`.

## 🛠️ Installation et Déploiement

Le projet est entièrement statique. Il n'y a pas d'étape de build ou de compilation nécessaire.

### En local :
1. Clonez le dépôt :
   ```bash
   git clone https://github.com/AlexisBidjebele237/djangou-landing-page.git
   ```
2. Ouvrez simplement le fichier `index.html` dans votre navigateur (ou utilisez une extension comme Live Server sur VSCode).

### Déploiement :
Le projet est prêt à être hébergé sur n'importe quel service d'hébergement de fichiers statiques :
- **Vercel**
- **Netlify**
- **GitHub Pages**
- **Cloudflare Pages**
